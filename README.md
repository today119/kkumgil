# 꿈길 걷기 프로젝트

인천영종고등학교 특색사업 「꿈길 걷기」(제10회, 2026.10.30~31) 지원 웹앱.

## 답사 지점 찍기
https://today119.github.io/kkumgil/survey/

사전답사 때 갈림길·명소·화장실·차량진입 지점 등을 현장에서 눌러 기록하고,
JSON / GPX 로 내보내는 도구. 설치 불필요, 브라우저에서 바로 사용.

- 기록은 기기(localStorage)에 자동 저장 — 앱을 꺼도 유지됨
- 인터넷이 끊겨도 지점 기록은 동작(지도만 안 보임)
- 지도: 카카오맵 JavaScript SDK
